> 在积分过期之前，把每一分都花在单位价值最高的去路上。

基于**麦当劳中国官方 MCP** 的 AI Skill：把「麦麦商城兑换」和「积分抽奖」两条去向折算到同一个尺子上比较，用背包 DP 在清算预算内求出最优组合，并对到期日发出预警。

---

## 它解决什么问题

积分是有**时效**的资产，但大多数人面对它时只有三个动作：攒着、到期前随手换一个、忘了它。真正的问题是：

- 不知道自己有多少积分**即将过期**
- 不知道换哪个商品的**单位价值最高**
- 不清楚**抽奖**是否真的比**直接兑换**划算
- 手里有一笔预算，却凑不出总价值最大的组合——贪心地按单价从高到低买，最后总会剩下一堆无处安放的零碎积分，照样过期

本项目把这四件事变成可计算的步骤，最后产出一份**带数字、可直接执行**的兑换清单。

---

## 一个反直觉的结论

在常见的奖品池下，**积分抽奖的期望价值通常低于直接兑换**。

举个真实计算的例子（单次消耗 500 积分的抽奖池）：

| 去路 | 单位价值 |
|---|---|
| 抽奖（加权期望） | 6.62 元 / 千积分 |
| 抽奖（悲观情况） | 0.00 元 / 千积分 |
| 麦咖啡拿铁（直接兑换） | **11.05 元 / 千积分** |

直接兑换比抽奖高出约 67%。而「抽奖」的直觉吸引力往往让人忽略这一点——这正是需要把两条去向放到同一把尺子上量的原因。

抽奖是**不确定收益**，因此本项目不只比较期望值，还会按风险偏好做调整后再下结论。

## 三步核心机制

### 1. 估值：把不同去向折算到同一把尺子

```text
VPP = 商品现金价 ÷ 商品积分价        （单位：元 / 积分，展示用「元 / 千积分」）
```

能精确算的精确算；不能精确算的**明确标注，不假装算得准**：

| 情况 | 处理 | 标注 |
|---|---|---|
| 同时有官方现金价与积分价 | `现金价 ÷ 积分价` | 【准】 |
| 只有积分价，同类目有样本 | 同类目 VPP 中位数 | 【估】 |
| 只有积分价且同类目无样本 | 全站 VPP 中位数 | 【估】置信度低 |
| 无任何可比价格 | 排除出推荐 | — |

### 2. 决策：抽奖 vs 兑换，按风险定价

```text
调整后抽奖价值 = 单位期望价值 × (1 − 不确定度 × 惩罚系数)
抽奖门槛      = 最佳商品 VPP × (1 + 溢价要求)
```

抽奖的不确定性体现在两个系数里：**不确定度**（概率已披露取 0.25，未披露取 0.60）与**风险偏好**。

| 风档 | 惩罚系数 | 溢价要求 | 适用 |
|---|---|---|---|
| 保守 | 0.90 | 20% | 稳一点，不冒险 |
| 均衡 | 0.50 | 8% | 默认 |
| 激进 | 0.15 | 0% | 就想抽一把 |

### 3. 择优：背包 DP，而不是贪心

「怎么在预算内凑出总价值最大」是背包问题。**按单价贪心会留下大量无处安放的零碎积分**，因此用 0/1 背包 DP 求解，并输出预算利用率。

> 默认**只让有官方现金价的商品**参与择优。估算商品虽然 VPP 可能好看，但那个数字本身是推算出来的——让推算值主导最优化，等于用假数字替你做决定。它们会被单独列进「待定清单」，交给你自己判断。需要纳入时加 `--include-estimated`。

## 安装方法

**前置条件**：在 <https://open.mcd.cn/mcp> 用手机号登录后申请 MCP Token（约 1 分钟）。

```bash
# 1. 获取代码
git clone https://github.com/sunqichao/mcd-points-sunset.git
cd mcd-points-sunset

# 2. 配置 Token（.env 已被 gitignore，不会误提交）
cp .env.example .env
#   编辑 .env，把 MCD_MCP_TOKEN 换成你的真实 Token

# 3. 运行清算（只读，不会消耗任何积分）
python3 src/pipeline.py
```

Python 3.9+，**无需 pip install**——全部依赖标准库。

未申请 Token 也能立刻看到完整效果：

```bash
python3 src/pipeline.py --mock      # 用内置样例数据跑通全链路
python3 tests/test_core.py          # 28 项算法断言
python3 src/build_demo.py           # 生成可视化看板 demo/index.html
```

### 在 WorkBuddy / Claude / Cursor 中作为 Skill 使用

将 [`mcp-config.example.json`](./mcp-config.example.json) 的内容粘贴到 MCP 配置中并替换 Token，然后启用 `SKILL.md`。之后直接对话即可：

> 「我的麦麦积分怎么花最值」
> 「积分还有多久过期」
> 「用积分抽奖划算吗」

## 安全设计

这是本项目最在意的部分——它能触达的是**用户真实的积分资产**：

- **默认只读**。常规运行只调用 4 个查询类工具，**绝不**调用 `draw-lottery` / `mall-create-order`
- **双开关写保护**。即便显式要求执行，也需同时通过 `--execute` 与 `--i-know-this-costs-points`
- **凭证隔离**。Token 只从环境变量读取；仓库内只有 `${MCD_MCP_TOKEN}` 占位符，`.gitignore` 已排除 `.env` 与真实响应产物
- **知情而非代劳**。估算商品不参与自动择优；抽奖「谢谢参与」类奖品按 0 值参与期望计算，避免系统性高估抽奖收益
